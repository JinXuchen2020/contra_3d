# 视觉回归基线 — shooter_contra

## 1. 截图采样点

| 采样点 | 说明 |
|--------|------|
| spawn（出生点） | 关卡开始 1–2 秒后截取，验证场景加载完整 |
| combat（战斗中） | 与敌人交火时截取，验证弹道/命中特效 |
| boss_room（Boss 房） | Boss 出现并完成入场动画后截取 |
| death_ui（死亡界面） | 角色死亡后截取，验证死亡覆盖层/重试 UI |

## 2. 最低渲染要求

- 3D 场景已渲染（非空白/纯色背景），网格与光照可见。
- 角色模型可见且位于出生点附近。
- UI 准星在画面中心区域可见。

## 3. 判定标准

**通过**：场景非空白；准星/HP 条/弹药计数等 UI 元素存在；采样点截图与基线差异在容忍度内。
**失败**：场景空白、角色丢失、UI 元素缺失、大面积花屏/黑块。

## 4. 基线更新规则

- 有意改动视觉表现时，人工确认后更新基线截图，并在提交说明中注明原因。
- 无意图的视觉差异按回归 bug 处理，禁止直接覆盖基线。
